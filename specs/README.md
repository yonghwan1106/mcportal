# specs/ — 컴파일 산출물 커밋 규약

이 디렉터리에는 MCPortal 컴파일러가 만든 **OpenAPI 3.1 스펙과 응답 샘플**이 들어간다.

```
specs/
  README.md
  demo/                 # 합성 픽스처로 만든 무키 재현 경로의 증거물
    openapi.json
    samples/
      getDemoList_01.json
      getDemoList_02.json
      getDemoList_03.json
  data.go.kr/           # 실 서비스 프리셋이 들어올 자리(W3). W2 시점에는 비어 있다.
```

## 1. 생성물이지만 커밋한다

산출물은 스크립트가 만들어 내는 파일이다. 그럼에도 리포에 커밋하는 이유는
**런타임이 LLM에 의존하지 않는다**는 설계를 파일로 증명하기 위해서다. 스펙 변환은
설치 시점·빌드 시점에 끝나 있고, 실행 시점에는 이 JSON을 읽을 뿐이다. 기능테스트가
인증키 없이도 전 구간을 돌릴 수 있는 근거도 여기 있다.

## 2. 재생성 명령

```
python examples\compile_demo.py
```

네트워크 호출 0건, 인증키 0건으로 돈다. 스크립트는 산출물 경로와 sha256 지문을
출력하고, 인증키 파라미터 비노출·취득 시각 비유출을 스스로 점검한다.

## 3. 재생성 결과는 바이트 동일해야 한다

같은 입력이면 같은 바이트가 나온다. 달라지면 결정론 회귀이므로 **버그**다.
`compile_demo.py`는 기존 산출물이 있으면 재생성 결과와 바이트를 비교해, 달라졌을 때
비정상 종료(코드 1)한다. 결정론을 지키기 위해 문서에는 생성 시각·호스트명·사용자명·
`fetched_at`을 싣지 않는다.

## 4. 파일 규약

| 항목 | 값 |
|---|---|
| 인코딩 | UTF-8(BOM 없음) |
| 개행 | LF(`\n`)만. CRLF 금지 |
| 끝 개행 | 정확히 1개 |
| 키 순서 | `sort_keys=True`(전 객체 키 알파벳 오름차순) |
| 들여쓰기 | 공백 2칸 |
| 비ASCII | 이스케이프하지 않는다(`ensure_ascii=False`) — 한국어 설명이 그대로 읽힌다 |

`.gitattributes`가 개행을 건드리지 않는지 확인할 것. Windows에서 CRLF가 섞이면 같은
내용이 다른 바이트가 되어 3의 재현성 주장이 무너진다.

## 5. 인증키·개인정보는 어떤 산출물에도 들어가지 않는다

- 스펙 문서에 `security`·`securitySchemes`를 만들지 않는다. 인증키는 트랜스포트가
  주입하며, 그 사실만 `info.x-mcportal.key_injection: "transport"`로 남긴다.
- 소스 스펙에 인증키 파라미터가 있어도 중간표현 단계에서 제거되고, 남아 있으면
  컴파일이 `CompileError`로 실패한다(2중 방어).
- 사람이 손으로 채우는 자유문자열(`source_url`·`license_note`·`description`·`title`)에
  인증키 값이 붙어 있으면 `build_openapi`가 `CompileError`로 거부한다. `write_spec`도
  저장 직전 문서 전체를 한 번 더 훑는다 — 스펙 문서를 실키가 붙은 URL로 받아 온 뒤
  그 URL을 그대로 기록하는 것은 자연스러운 사용법이라, 게이트가 없으면 커밋 산출물로
  자격증명이 나간다.
- 응답 샘플은 저장 직전 시크릿 스크러빙(`scrub_text`)을 한 번 더 거친다. 응답 본문이
  요청 키를 되비추는(echo) 실제 사례가 있기 때문이다. 이 두 번째 방어선이 기본값으로
  꺼지지 않도록 **`write_samples(secrets=...)`는 키워드 필수 인자**다. 무키 경로도
  `secrets=[]`를 명시해 "지울 시크릿이 없음"을 선언한다.

## 6. 실데이터 유래 산출물은 등재 후에만 커밋한다

`specs\data.go.kr\` 아래에 들어갈 **실 서비스 유래 산출물**(응답 샘플 포함)은
`NOTICE-DATA.md`에 KOGL 유형·제공 기관·취득일을 등재한 뒤에만 커밋한다.
`specs\demo\`는 100% 합성 픽스처(가상 기관 · `.invalid` 도메인)이므로 등재 대상이
아니다.
