# 15081808 — 국세청 사업자등록정보 진위확인·상태조회

사업자등록번호 목록으로 휴폐업·과세유형을 조회하는 `status` 와, 번호·대표자성명·
개업일자를 대조하는 `validate` 두 오퍼레이션짜리 프리셋이다. 둘 다 **POST 본문형**
이라는 점이 이 번들의 특징이다.

## 3. 큐레이션이 바꾼 것 / 바꾸지 않은 것

**바꾼 것**

- **서비스 설명 교체(필수 조치).** 원 스펙의 `info.description` 은 공식 사용
  안내라 인증키 자리표시자가 붙은 호출 예시 URL 을 담고 있다. 그대로 두면 시크릿
  게이트에 걸려 컴파일이 중단된다. 게이트를 완화하는 대신 **사람이 확인한
  요약문으로 교체**했다(2층 구조가 실제로 값을 하는 지점).

  ⚠️ **부작용 — 이 프리셋은 큐레이션을 끈 컴파일이 불가능하다.**
  `compile_preset(directory, curated=False)` 는 교체 전 원문 설명을 그대로 쓰므로
  시크릿 게이트에 걸려 `CompileError` 가 난다(직접 확인: 나머지 3종은 정상).
  따라서 **K2 벤치마크의 "자동생성 단독" 대조군을 이 프리셋에서는 만들 수 없고**,
  K2 의 S1·S2·S3 는 전부 미측정으로 보고한다. 게이트를 완화해 대조군을 만드는
  선택은 하지 않는다. 이 한계는
  [`../../benchmarks/PROTOCOL.md`](../../benchmarks/PROTOCOL.md) §8-2 **L8** 에도
  등재돼 있다.
- 두 오퍼레이션의 요약·설명. 특히 **요청 본문 형식**을 설명 본문에 적었다 —
  요청 본문 스키마는 패스스루라 파라미터 힌트로는 표현할 수 없기 때문이다.
- 서로를 가리키는 문장("영업 중인지만 확인하면 상태조회가 더 간단하다").
- 예시 프롬프트 5개, 파라미터 힌트(`returnType`).

**바꾸지 않은 것**

- 요청 본문 스키마, 파라미터의 타입·필수 여부, 경로, 메서드.
- **응답 스키마**(§4).

## 4. 응답 스키마를 그대로 둔 이유

이 프리셋만 `response.unresolved` 를 쓰지 않았다. 근거는 이 스키마가 **소스가
직접 선언한** 정의(12종·최대 11필드)이고, 정찰이 실제 응답과의 불일치를 지적하지
않았기 때문이다(합성이 아니다). 다만 **예시값은 전부 자리표시자이며, 필드 구조는
v0.2 실키 샘플 1건으로 재확인한다.**

전부 미확정으로 통일하고 싶다면 `curation.json` 에 아래 한 블록을 넣으면 되고
**코드 변경은 필요 없다.**

```json
"response": {"unresolved": true, "reason": "…근거…"}
```

## 5. 어댑터 동작에 대한 기록

- **본문형 오퍼레이션에 페이징 파라미터를 붙이지 않는다.** odcloud 공통 파라미터
  보강은 오퍼레이션 형태를 본다 — 요청 본문이 조회 대상을 정하는 오퍼레이션에는
  `page`·`perPage` 를 보강하지 않는다. 그 둘은 이 API 에서 의미가 없고, LLM 이
  채워 보내면 조용히 무시되거나 오류가 된다. `returnType` 은 응답 형식 역할이므로
  유지한다(원 스펙의 사용 안내가 질의 문자열 전달을 명시한다).
- `responses` 에 비-HTTP 키 `-5` 가 섞여 있다. 어댑터는 200 만 읽으므로 무해하다.
- 원 스펙의 `securityDefinitions` 에는 질의 파라미터 경로와 헤더 `Authorization`
  경로가 둘 다 선언돼 있다. 중간표현은 키의 **위치**를 표현하지 않으므로 사실만
  여기와 `curation.json` 의 `service.notes` 에 기록한다(W4 이월).

## 6. 미해결 항목 (v0.2)

1. `returnType` 을 실제로 받는지, `page`·`perPage` 를 정말 무시하는지 실호출 확인.
2. 응답 필드 구조 재확인(예시값이 전부 자리표시자라 형태만 알 수 있다).
3. 인증키 위치(query/header) 표현 — W4 이월.

## 7. 개인정보

원 스펙의 예시값은 전부 자리표시자다(`0000000000` · `홍길동` · `(주)테스트` ·
`20000101`). 실 사업자등록번호·실명 **0건**이며, 근거와 목록은
[`../NOTICE-DATA.md`](../NOTICE-DATA.md) §2 에 있다.

⚠️ 이 API 는 **요청 본문에 사업자등록번호가 실린다.** 카세트 기록·로그 보관 시
이름 기반이 아니라 **값 기반 스크러빙**이 필요하다.
