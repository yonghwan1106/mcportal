# benchmarks — MCPortal 자체 계층 비용 계량

```
# 프로토콜 준수 실행(정본)
python benchmarks/harness.py --label <라벨>

# 스모크(수치를 인용하지 말 것)
python benchmarks/harness.py --quick --label smoke
```

결과는 `results/bench_<YYYYMMDD>_<label>.json` 에 쌓인다. 측정 계획은
[`PROTOCOL.md`](PROTOCOL.md) 에 **실행 전에** 확정되어 있으며, 하네스는 그 문서에
없는 항목을 재지 않는다.

## 이 수치는 무엇이 아닌가

- **경쟁 라이브러리 벤치마크가 아니다.** 다른 MCP 브리지·OpenAPI 변환기를 같은
  조건에서 재지 않았다. 여기서 재는 것은 **MCPortal이 스스로 얹은 계층의 비용**이다.
  B4의 `bare` 대조군은 "MCPortal이 없을 때"이지 "다른 제품을 썼을 때"가 아니다.
- **실서비스 종단 지연이 아니다.** 네트워크 왕복·게이트웨이 처리·LLM 추론 시간이
  전부 빠져 있다.
- **큐레이션 효용의 증거가 아니다.** 2층 구조의 효용은 실키 단계 항목(K2)에서만
  판정되며, 그 항목은 아직 실행되지 않았다.
- **정확도 측정이 아니다.** 무키 5종에는 정확도 축이 없다. 빠르다는 것이 옳다는
  뜻은 아니다.

전체 한계 목록은 `PROTOCOL.md` §8을 읽는다.

## 측정 항목

| ID | 항목 | 대조군 |
|---|---|---|
| B1 | replay 왕복 지연 | 응답 페이로드 1 KB / 64 KB |
| B2 | 스크러빙 오버헤드 | 함수 3종 x 크기 2종 x 시크릿 0·3개 |
| B3 | 컴파일 시간 + 결정론 | 합성 소스 3종 (+ 프리셋 번들이 있으면 함께) |
| B4 | 쿼터가드 오버헤드 | 가드 배선 vs bare `httpx.MockTransport` |
| B5 | FastMCP 도구 빌드 시간 | 합성 문서 (+ 프리셋 `openapi.json`) |

전 항목 **네트워크 호출 0건 · 인증키 0건 · 실응답데이터 0건**이다. 입력은 100%
합성이며 도메인은 예약 TLD `.invalid` 를 쓴다.

## 결과 파일 읽는 법

```jsonc
{
  "protocol": "benchmarks/PROTOCOL.md@<지문>", // 어느 판본으로 쟀는지
  "mode": "full",                              // "quick" 이면 인용 금지
  "overrides": {},                             // 비어 있어야 프로토콜 기본 반복 수
  "environment": { … },                        // 하드웨어·버전(개인정보 0)
  "items": [ { "id": "B4", "conditions": [ … ], "derived": { … } } ]
}
```

- 시간 단위는 전부 **나노초**다. 표시할 때만 환산한다.
- 정본 요약값은 `median_ns` 와 `p95_ns` 다. `p95` 는 nearest-rank 정의이며
  보간하지 않는다(`PROTOCOL.md` §4).
- `samples_ns` 에 원자료가 그대로 들어 있다. 이상치를 제거하지 않았으므로
  직접 재검산할 수 있다.
- `status`가 `"skipped"` 인 항목·조건은 실패가 아니다. 프리셋 번들이나 fastmcp가
  없는 환경에서 정상적으로 나타난다.
- 종료 코드: 0 정상 / 1 항목 실패·저장 차단 / 2 사용법 오류.

## 아직 비어 있는 것

실키 단계 항목 **K1(자동변환 성공률) · K2(툴콜 성공률: 자동생성 단독 vs 큐레이션) ·
K3(응답 스키마 추론 정확도)** 는 `PROTOCOL.md` §6에 **정의만** 되어 있고 아직
실행되지 않았다. 인증키·`CALL_BUDGET` 하드 가드 확보가 실행 조건이며, 정의를 미리
적어 둔 이유는 키를 얻은 뒤에 유리한 판정 기준을 고르는 일을 막기 위해서다.
